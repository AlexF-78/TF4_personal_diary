# Personal Diary Django Project

Веб-приложение для личного дневника.

## Установка

1. Клонировать репозиторий
2. Установить Poetry: `pip install poetry`
3. Установить зависимости: `poetry install`
4. Активировать виртуальное окружение Poetry: `poetry shell`
5. Применить миграции: `python manage.py migrate`
6. Запустить сервер: `python manage.py runserver`
