# Личный Дневник - Веб-приложение на Django

## Функционал
- **Регистрация и аутентификация** пользователей (вход/выход)
- **CRUD операции** с записями дневника (создание, редактирование, удаление)
- **Просмотр записей**: список всех записей и детальный просмотр отдельной
- **Поиск** по заголовку и содержимому записей
- **Адаптивный и современный дизайн** с использованием Bootstrap 5

## Технологии
- **Backend**: Django 6.0, Python 3.12
- **База данных**: PostgreSQL 15
- **Frontend**: Bootstrap 5, Django Templates
- **Контейнеризация**: Docker, Docker Compose
- **Управление зависимостями**: Poetry
- **Качество кода**: Black, Flake8, isort

## Быстрый старт с Docker 

### Предварительные требования
- Установленные Docker и Docker Compose
- Установленный Git

### Установка

1. **Клонируйте репозиторий**:
   ```bash
   git clone <repository-url>
   cd PersonalDiary
   ```
2. **Создайте и настройте файл окружения**:

   ```bash
    cp .env.sample .env 
   ```
   Отредактируйте файл .env, указав, например, DEBUG=True для разработки.
   
3. **Запустите сборку и запуск контейнеров**:

   ```bash
   docker-compose up --build -d
   ```
   Эта команда соберёт Docker-образ и запустит два контейнера: с приложением Django (web) и базой данных PostgreSQL (db).
   
4. **Примените миграции базы данных**:
   Миграции применяются автоматически при запуске. При необходимости вы можете выполнить их вручную:
   ```bash
   docker-compose exec web python manage.py migrate
   ```
5. **Создайте учетную запись администратора (опционально, для доступа в админ-панель):**

   ```bash
   docker-compose exec web python manage.py createsuperuser
   ```
   Следуйте инструкциям в терминале.
   
6. **Приложение готово к использованию!**

   - Веб-приложение доступно по адресу: http://localhost:8001

   - Админ-панель Django доступна по адресу: http://localhost:8001/admin

### Основные команды Docker для управления

```bash
# Остановить все запущенные контейнеры проекта
docker-compose down

# Просмотреть логи работы контейнера с приложением в реальном времени
docker-compose logs -f web

# Полная пересборка Docker-образов (полезно при изменениях в Dockerfile)
docker-compose build --no-cache

# Выполнить любую команду Django внутри контейнера (например, создать новое приложение)
docker-compose exec web python manage.py startapp new_app
```

   
### Установка для локальной разработки (без Docker)
Этот способ подходит, если вы хотите вносить изменения в код и сразу видеть результат.

### Предварительные требования
- Python 3.11 или новее
- PostgreSQL 15 или новее
- Установленный Poetry (pip install poetry)

### Установка и запуск
1. **Клонируйте репозиторий и перейдите в папку проекта**:

   ```bash
   git clone <ваш-адрес-репозитория> PersonalDiary
   cd PersonalDiary
   ```
2. **Установите зависимости Python с помощью Poetry**:

   ```bash
   poetry install
   ```
3. **Активируйте виртуальное окружение Poetry**:

   ```bash
   poetry shell
   ```
4. **Настройте базу данных PostgreSQL**:
   - Создайте новую базу данных с именем `personal_diary`.
   - Создайте файл `.env` на основе примера:

      ```bash
      cp .env.sample .env
      ```
   - Откройте `.env` и укажите реальные параметры подключения к вашей PostgreSQL (имя пользователя, пароль, хост).

5. **Примените миграции для создания таблиц в базе данных**:

   ```bash
   python manage.py migrate
   ```
6. **Создайте суперпользователя (опционально)**:

   ```bash
   python manage.py createsuperuser
   ```
7. **Запустите сервер для разработки**:

   ```bash
   python manage.py runserver
   ```
8. **Откройте браузер и перейдите по адресу http://127.0.0.1:8000**

### Использование приложения

- **Регистрация**: Перейдите по ссылке "Создать дневник" на странице входа или по адресу `/register/`.

- **Вход**: Используйте форму на главной странице или адрес `/accounts/login/`.

- **Создание записи**: Нажмите кнопку "Новая запись" в навигационной панели.

- **Просмотр и редактирование**: Все ваши записи отображаются на главной странице. Для просмотра, редактирования или удаления нажмите на соответствующую кнопку у нужной записи.

- **Поиск**: Используйте поисковую строку в верхней части страницы со списком записей.

### Настройка окружения (файл .env)
Перед запуском необходимо создать файл `.env` в корне проекта, скопировав его из шаблона:

```bash
cp .env.sample .env
Заполните файл .env своими значениями. Этот файл содержит критически важные настройки и никогда не должен попадать в систему контроля версий (Git).
```
#### Минимальный набор настроек для `.env`:

```bash
# Обязательно сгенерируйте новый уникальный ключ для продакшена!

```
